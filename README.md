# Задачи на массивы

1. Напишите функцию ```int get_second_max(int*, size_t)```, которая находит второй по величине элемент и возвращает его.
2. Напишите функцию ```int is_alternating(int*, size_t)```, которая возващает ```1```, если ряд чисел, передающийся в качестве параметра знакопеременный и ```0```, если нет.
3. Напишите функцию ```void remove_gt_one(float*, size_t)```, которая удаляет из массива все элементы, модуль которых не превышает 1 и заменяет удаленные элементы нулями и сдвигает в конец массива.
4. Напишите функцию ```int get_greater_freq(int*, size_t)```, которая находит элемент, который встречается в массиве наибольшее число раз.
5. Напишите функцию ```int get_greater_series(int*, size_t)```, которая находит самую длинную серию подряд идущих одинаковых элементов и возвращает число, из которого состоит серия.
